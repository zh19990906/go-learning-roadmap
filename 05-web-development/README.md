# Stage 05 · Web 开发

## 目标
理解 HTTP 基础并能构建 REST API。

## 学习顺序
1. net/http
2. Handler / Request / Response
3. JSON API
4. REST 设计
5. middleware
6. Gin

## 阶段项目
实现内存版 Todo API：
- GET /todos
- GET /todos/{id}
- POST /todos
- PUT /todos/{id}
- DELETE /todos/{id}

## 阶段验收
不依赖框架也能解释一次 HTTP 请求在 Go 服务中的完整处理过程。
