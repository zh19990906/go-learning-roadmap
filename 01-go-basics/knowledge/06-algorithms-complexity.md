# 排序、二分与复杂度

## 冒泡排序

核心是比较相邻元素：

```go
if nums[j] > nums[j+1] {
    nums[j], nums[j+1] = nums[j+1], nums[j]
}
```

如果一整轮没有交换，可以提前结束。

复杂度：

```text
平均/最坏 O(n²)
最好（有提前结束）O(n)
额外空间 O(1)
```

## 二分查找

前提：数据已经有序。

常见中点：

```go
mid := left + (right-left)/2
```

边界更新：

```go
right = mid - 1
left = mid + 1
```

循环常见写法：

```go
for left <= right
```

复杂度：

```text
时间 O(log n)
空间 O(1)
```

## 注意

如果为了查一次数据，先做 O(n²) 冒泡排序再 O(log n) 查找，整体仍由排序主导。二分的优势常见于“数据已排序”或“排序一次，多次查询”。
