# Stage 01 · Go 基础强化

## 目标
熟练使用数组、slice、map、string、函数，并建立基本的 Go 编程习惯。

## 核心知识
- array 与 slice
- append / copy
- map
- range
- string / rune / byte
- 函数与多返回值
- 指针基础
- 基础复杂度意识

## 推荐练习顺序
1. 数组第二大值
2. Slice 原地反转
3. Map 实现去重
4. 元素频次统计
5. 字符串回文判断
6. 二分查找
7. 插入排序
8. 快速排序

## 阶段验收
不依赖答案，能独立完成 slice / map / string 相关基础题，并能解释时间复杂度与边界条件。
