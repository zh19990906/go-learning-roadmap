# Stage 01 · Go 基础强化

## 目标
熟练使用数组、slice、map、string、函数，并建立基本的 Go 编程习惯。

## 学习前先读
进入 [knowledge/README.md](./knowledge/README.md)。

这里已经拆分了：
- Slice / Array
- Map / Set
- String / byte / rune / Unicode / unicode 包
- 函数、多返回值、零值
- 指针与 Slice 底层数组
- 排序、二分、复杂度
- Stage 01 常见坑

## 推荐练习顺序
1. 数组第二大值
2. Slice 原地反转
3. Map 实现去重
4. 元素频次统计
5. 字符串回文判断
6. 二分查找与排序复习

## 阶段验收
不依赖答案，能独立完成 slice / map / string 相关基础题，并能解释时间复杂度与边界条件。
